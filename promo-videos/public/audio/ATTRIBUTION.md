# Audio attribution and production note

The music and cinematic sound effects in the BGM versions are copied from the
installed `video-shotcraft` asset library. The library records them as Mixkit
assets covered by the Mixkit License (free commercial use; attribution not
required). The original batch download lost the exact BGM track URL, so the
track should be re-audited against the current Mixkit catalog before a public
commercial campaign.

Files used:

- `bgm-tech-house.mp3`
- `transition-soft.mp3`
- `whoosh-big.mp3`
- `swoosh-quick.mp3`
- `riser-cine.mp3`
- `impact-deep-whoosh.mp3`
- `sparkle.mp3`

Every final composition also has a `-no-bgm.mp4` render from the same visual
timeline. Those versions retain cinematic SFX but omit the music bed.
